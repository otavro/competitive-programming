# Competitive Programming

This repository is dedicated to my studies and practice in competitive programming and problem solving.

It contains algorithm implementations, data structures, and solutions to problems from online judges such as BeeCrowd and LeetCode. The goal is to build strong fundamentals, recognize common patterns, and continuously improve logical reasoning and coding skills.

## Repository Structure

### Algorithms
Core algorithms and data structures organized by topic, focusing on understanding concepts, complexity analysis, and reusable implementations.

Examples:
- Sorting and searching algorithms
- Graph algorithms (BFS, DFS, shortest paths)
- Dynamic programming
- Greedy techniques
- Mathematical algorithms
- Fundamental data structures

### BeeCrowd
Solutions to BeeCrowd problems, organized by category and difficulty, following good coding practices and clear logic.

### LeetCode
Solutions to LeetCode problems grouped by patterns and topics commonly used in technical interviews, such as arrays, trees, graphs, and dynamic programming.

### Notes
Personal notes, summaries, and references about algorithmic complexity, problem-solving patterns, and general competitive programming tips.

## Learning Goals
- Strengthen algorithmic thinking
- Improve problem-solving speed and accuracy
- Master common competitive programming patterns
- Prepare for coding interviews and contests

Languages and tools may vary as the repository evolves.
